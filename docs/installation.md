## System Requirements

Server 8.1 supports Laravel 10–13 and requires PHP 8.1 or later. Use the PHP version required by your Laravel release. Install packages with [Composer](https://getcomposer.org/).

---


## Install via Composer

Navigate to your project directory and install Sajya using Composer:

```bash
$ cd my-application
$ composer require "sajya/server:^8.1"
```

Upgrading from server 7.x? Follow the [upgrade guide](/docs/upgrade).
